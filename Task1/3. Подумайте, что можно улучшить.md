# Защита конфиденциальных данных в "Медикаменте"

## 1. Список данных для защиты и способы защиты

| Категория данных             | Примеры                                        | Уровень чувствительности | Способы защиты                                                |
|------------------------------|------------------------------------------------|--------------------------|---------------------------------------------------------------|
| **Идентификационные данные** | ФИО, дата рождения, паспортные данные          | Высокий                  | Шифрование при хранении и передаче, контроль доступа          |
| **Контактные данные**        | Телефон, email, адрес                          | Средний                  | Шифрование при хранении, частичная обфускация при отображении |
| **Медицинские данные**       | Диагнозы, результаты анализов, история болезни | Очень высокий            | Шифрование, строгий контроль доступа, аудит действий          |
| **Финансовые данные**        | Информация о платежах, банковские реквизиты    | Высокий                  | Шифрование, токенизация, сегментация хранения                 |
| **Данные о записях**         | Даты и время приемов, специалисты              | Средний                  | Обезличивание в отчетах, контроль доступа                     |
| **Учетные данные**           | Логины, пароли сотрудников                     | Высокий                  | Хеширование паролей, многофакторная аутентификация            |
| **Данные о сотрудниках**     | Персональные данные врачей и персонала         | Средний                  | Шифрование, разграничение доступа                             |
| **Данные о ТМЦ**             | Информация о лекарствах, оборудовании          | Низкий                   | Контроль доступа, аудит изменений                             |

## 2. Механизм тегирования данных

### Система тегов для классификации данных

| Тег    | Описание                                | Примеры данных                   |
|--------|-----------------------------------------|----------------------------------|
| `PII`  | Персонально идентифицируемая информация | ФИО, паспортные данные, адрес    |
| `PHI`  | Защищенная медицинская информация       | Диагнозы, результаты анализов    |
| `FIN`  | Финансовая информация                   | Данные о платежах, реквизиты     |
| `AUTH` | Аутентификационные данные               | Учетные записи, пароли           |
| `INT`  | Внутренние данные компании              | Расписания, внутренние документы |
| `PUB`  | Публичная информация                    | Общедоступные сведения           |

### Уровни конфиденциальности

| Уровень | Описание                       | Требуемые меры защиты                                             |
|---------|--------------------------------|-------------------------------------------------------------------|
| `L0`    | Публичные данные               | Базовая защита целостности                                        |
| `L1`    | Внутренние данные              | Базовый контроль доступа                                          |
| `L2`    | Конфиденциальные данные        | Шифрование, строгий контроль доступа                              |
| `L3`    | Строго конфиденциальные данные | Полное шифрование, многофакторная аутентификация, детальный аудит |

### Инструменты для тегирования данных

1. **Microsoft Information Protection (MIP)**:
    - Автоматическая классификация документов
    - Применение политик защиты на основе тегов
    - Отслеживание действий с защищенными документами

## 3. Инструменты, способы и меры обеспечения конфиденциальности данных

### Технические инструменты

1. **Шифрование данных**:
    - **OpenSSL** - шифрование при передаче данных
    - **VeraCrypt** - создание зашифрованных контейнеров для файлов
2. **Управление доступом**:
    - **RBAC-системы** - управление на основе ролей
3. **Аудит и мониторинг**:
    - **ELK Stack** - анализ логов и выявление аномалий
4. **Безопасное хранение**:
    - **SQL Server с TDE** - прозрачное шифрование данных

### Организационные меры

1. **Политики и процедуры**:
    - Политика классификации данных
    - Процедуры обработки конфиденциальной информации
    - Регламенты реагирования на инциденты
2. **Обучение персонала**:
    - Тренинги по информационной безопасности
    - Осведомленность о социальной инженерии
    - Обучение работе с защищенными данными
3. **Контроль соответствия**:
    - Регулярные аудиты безопасности
    - Оценка соответствия требованиям регуляторов
    - Тестирование на проникновение
